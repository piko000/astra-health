# M5 — NASA OSD-575 research data integration

Verified and downloaded on **15 November 2026**. This integration is separate
from Synthetic Mission Telemetry and Demo Alert Rules.

## Study and provenance

- Provider: NASA Open Science Data Repository, OSD-575 / ALSDA LSDS-8.
- Title: *SpaceX Inspiration4 Blood Serum Metabolic Panel and Immune/Cardiac
  Cytokine Arrays (Comprehensive Metabolic Panel and Multiplex)*.
- [Official study and Files panel](https://osdr.nasa.gov/bio/repo/data/studies/OSD-575).
- Dataset DOI: [10.26030/mc5d-p710](https://doi.org/10.26030/mc5d-p710).
- Study version: **3**. Official study index lists its metadata update as
  11 June 2024; the downloaded metadata API also reports version 3.
- License: **CC0-1.0**, as stated on the official NASA study page indexed during
  verification. Citation and participant pseudonyms are retained.
- [NASA file catalog API](https://osdr.nasa.gov/osdr/data/osd/files/575/) returned
  HTTP 200 and lists both downloaded files as visible and unrestricted.
- [NASA study metadata API](https://osdr.nasa.gov/osdr/data/osd/meta/575) returned
  HTTP 200. Its response is saved as `study_metadata.json`.

The study concerns four private Inspiration4 crew members and serum collected
before/after the September 2021 mission. No in-flight daily heart-rate series
is present in the CMP file. The protocol describes fresh serum sent to Quest
Diagnostics, test code 10231, analyzed on a Beckman Coulter AU5800.

## Measurements and units

The CSV has one sample identifier and 19 sets of value/reference-range columns.
This bounded first integration exposes six existing measurement columns:

| UI biomarker | Exact source column | Original unit |
| --- | --- | --- |
| Glucose | `glucose_value_milligram_per_deciliter` | mg/dL |
| Albumin | `albumin_value_gram_per_deciliter` | g/dL |
| Creatinine | `creatinine_value_milligram_per_deciliter` | mg/dL |
| Sodium | `sodium_value_millimol_per_liter` | mmol/L |
| Potassium | `potassium_value_millimol_per_liter` | mmol/L |
| Total bilirubin | `total_bilirubin_value_milligram_per_deciliter` | mg/dL |

Descriptions identify the serum constituent being measured; they do not interpret
health or disease. Units are abbreviated from source headers without conversion.
Source reference ranges are retained in the original CSV but are **not** applied
as alert thresholds. The remaining analytes, including calculated eGFR values and
ratios, are outside this view's scope. No cytokine array files were downloaded.

## Timepoints: metadata takes precedence over prose

The CSV joins to `s_OSD-575.txt` on the exact `Sample Name`. `Source Name` supplies
the participant pseudonym; `Factor Value[Time]`, `Unit` and
`Factor Value[Spaceflight]` supply collection timing. The assay metadata links
these samples to the requested transformed CMP file.

| Timepoint | Metadata meaning | Phase |
| --- | --- | --- |
| L-92 | Launch minus 92 days | Pre-flight |
| L-44 | Launch minus 44 days | Pre-flight |
| L-3 | Launch minus 3 days | Pre-flight |
| R+1 | Return plus 1 day | Post-flight |
| R+45 | Return plus 45 days | Post-flight |
| R+82 | Return plus 82 days | Post-flight |
| R+194 | Return plus 194 days | Post-flight |

All four pseudonyms C001–C004 have seven sample rows. The study description lists
six occasions, omitting R+194; the actual sample metadata and CSV both include it.
The UI therefore displays all seven. L and R use different reference events:
we do not manufacture a common mission-day axis or calendar dates. The x-axis
is explicitly categorical and not proportional to elapsed time.

## Missing values and validation

The source uses empty fields, `NA` and `N/A`. They remain missing values, never
zeroes or interpolated measurements. Among displayed biomarkers, total bilirubin
has 27 measured values and one missing value; the other five have 28 each.
The full CSV also has 22 missing BUN/creatinine ratios and missing reference bounds,
which are not part of the displayed subset.

The loader verifies pinned file hashes, required columns, numeric values,
nonfinite values, unique sample identifiers, metadata joins, organism, serum
material, day units and agreement between timepoint, phase and sample identifier.
Bad/missing files stop only the research chart with an actionable message.
The UI reports measured/missing counts and labels missing rows in the table.
Plots use separate participant symbols and measurement points only; no connecting
lines, interpolation, synthetic padding or inferred daily vital signs.

## Offline use and reproducible download

The bundled verified files support offline operation. The Streamlit app never
downloads data on startup or during navigation. To restore the pinned snapshot:

```powershell
.\.venv\Scripts\python.exe -m data.download_nasa
```

This explicit command requires internet. It queries NASA's public catalog and
metadata, checks version/public flags/file sizes/known SHA-256 hashes, and only
then writes the downloaded files. It refuses changed files instead of silently
accepting a new version. No unverified fallback is used. A future version requires
review of metadata, schema, units and tests before updating the pins.

unexpected S3 host before writing files; inspection confirmed NASA's redirects,

The [official challenge Resources URL](https://www.spaceappschallenge.org/2026/challenges/health-monitoring-software/?tab=resources)
was inaccessible through the research tool. Direct HTTPS requests on 15 November
2026 failed certificate verification (`unable to get local issuer certificate`),
including a retry with the system certificate store. TLS verification was not
disabled. This is an unresolved verification limit, not evidence that OSD-575
is absent or officially recommended. No substitute team project was used as proof.

## Scientific boundaries and submission wording

NASA Research Data = these six serum-biomarker views. Synthetic Mission Telemetry
= generated heart rate, sleep and activity in the original dashboard. Demo Alert
Rules = unchanged 10%/25% thresholds applied only to synthetic values.

The four-person observational cohort does not establish population norms,
causality, diagnostic accuracy or mission fitness. This is a research explorer,
not medical decision support. Suitable wording: “ASTRA Health combines a
synthetic monitoring demo with a separate explorer of verified NASA OSD-575
serum measurements.” Do not claim live NASA telemetry or clinical validation.
